# TG Assistant Bot (MVP)

Telegram-бот «персональная операционная система» для задач, настроения, привычек и здоровья.

## Возможности MVP
- Входящие сообщения в «инбокс» (текст, голос, документы).
- Задачи и напоминания.
- Цели и еженедельные чек-ины.
- Дневник настроения с графиком.
- Привычки, включая протокол «тяга».
- Импорт Apple Health (ZIP → export.xml) + базовые агрегаты.
- Экспорт и удаление данных.
- Дашборды с графиками.

## Требования
- Docker + Docker Compose
- Токен Telegram-бота

## Быстрый старт
1. Скопируй `.env.example` → `.env` и укажи BOT_TOKEN.
2. Запусти:
   ```bash
   docker compose up -d --build
   ```
3. Бот автоматически применит миграции и начнет работу.

## Команды (примеры)
- `/start` — старт
- `/add купить молоко завтра в 19:00` — добавить задачу
- `/tasks` — список задач
- `/done 1` — закрыть задачу
- `/mood` — мастер дневника настроения
- `/habit_create checkbox Читать` — новая привычка
- `/habit_log` — логирование привычки
- `/goal_add Выучить Python 2024-12-31` — цель
- `/goal_list` — список целей
- `/dashboard` — графики
- `/health` — подсказка по импорту Apple Health
- `/export` — выгрузка
- `/delete_data` — удаление

## Примеры ответов (текст)
- «Создал задачу #3 из сообщения.»
- «Сохранил запись настроения.»
- «Импорт завершен.»

## Тесты
```bash

```
Или:

## Настройки
Через `.env`:
- `BOT_TOKEN`
- `DATABASE_URL`
- `TZ` (по умолчанию Europe/Moscow)
- `WEEKLY_REVIEW_TIME`
